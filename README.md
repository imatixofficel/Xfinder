# Xfinder — پنل زنده کانفیگ‌های عمومی

**به نام خدا**  
Xfinder یک پروژه پایتون برای دریافت کانفیگ‌های عمومی از فهرست‌های متنی، حذف موارد تکراری، بررسی قالب و تست TCP محدود، و انتشار داشبورد استاتیک فارسی/انگلیسی است.

> نکته مهم: این پروژه اتصال VPN را تضمین نمی‌کند. تست TCP فقط نشان می‌دهد میزبان و پورت در زمان تست قابل دسترسی بوده‌اند؛ اعتبار TLS، SNI، UUID/Password و اتصال واقعی باید با کلاینت Xray یا هسته سازگار بررسی شود.
>
> این پروژه عمداً آدرس سرورهای کانفیگ را با IPهای Cloudflare جایگزین نمی‌کند. IPهای Cloudflare عمومی لزوماً مقصد مجاز یا قابل‌استفاده برای آن سرویس نیستند و جایگزینی ممکن است اتصال را خراب کند. فقط از سرورها و منابعی استفاده کنید که اجازه استفاده از آن‌ها را دارید.

## امکانات

- دریافت فهرست‌های عمومی VLESS، VMess، Trojan، Shadowsocks، Hysteria2 و TUIC
- حذف تکراری‌ها و دسته‌بندی پروتکل‌ها
- بررسی ساختار URI و تست TCP با محدودیت هم‌زمانی
- پیگیری سلامت منبع‌ها در SQLite
- خروجی `output/configs.json` و فایل‌های متنی دسته‌بندی‌شده
- داشبورد واکنش‌گرا با ظاهر روشن، کارت‌های گرد و سایدبار
- نمایش «به نام خدا» و انیمیشن اسکن در شروع
- تشخیص زبان از زبان مرورگر (فارسی/انگلیسی) و امکان تغییر دستی
- اجرای دستی یا زمان‌بندی‌شده با GitHub Actions

## نیازمندی‌ها

- Python 3.11 یا جدیدتر
- اتصال اینترنت برای دریافت منابع
- GitHub repository برای انتشار خودکار با GitHub Pages (اختیاری)

## اجرای محلی

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
python -m src.main
```

فایل‌های خروجی در پوشه `output/` ساخته می‌شوند. برای مشاهده داشبورد، فایل `output/index.html` را در مرورگر باز کنید یا از یک وب‌سرور محلی استفاده کنید:

```bash
python -m http.server 8000 --directory output
```

سپس `http://localhost:8000` را باز کنید.

## تنظیم منابع

منابع در `src/sources.py` هستند. هر منبع باید یک URL مستقیم به فایل متنی داشته باشد که در هر خط یک کانفیگ URI یا یک رشته Base64 از subscription باشد. منابع عمومی ممکن است حذف، کند یا از دسترس خارج شوند؛ فهرست را بررسی و به‌روزرسانی کنید.

منابع تلگرام به‌صورت خودکار از کانال‌ها جمع‌آوری نمی‌شوند؛ این کار به API، دسترسی مجاز و مدیریت محدودیت‌های تلگرام نیاز دارد. در این نسخه فقط URLهای مستقیم HTTP/HTTPS خوانده می‌شوند.

## تنظیم تست TCP

در `src/settings.py` مقدارهای زیر را تنظیم کنید:

- `TCP_CONCURRENCY`: هم‌زمانی تست (پیش‌فرض 50، سقف 100)
- `TCP_TIMEOUT_SECONDS`: زمان انتظار برای اتصال (پیش‌فرض 4 ثانیه)
- `MAX_CONFIGS_TO_TEST`: سقف کانفیگ‌های تست‌شده در هر اجرا

تست تعداد زیادی مقصد به‌صورت هم‌زمان می‌تواند فشار شبکه ایجاد کند؛ محدودیت پیش‌فرض را بالا نبرید مگر اینکه مجوز و ظرفیت لازم را داشته باشید.

## انتشار با GitHub Pages

1. کل محتویات ZIP را در یک repository جدید GitHub قرار دهید.
2. در repository به **Settings → Pages** بروید.
3. در بخش Build and deployment، گزینه **Deploy from a branch** و شاخه `main` و پوشه `/output` را انتخاب کنید. اگر `/output` در انتخابگر موجود نبود، از روش GitHub Actions برای انتشار artifact استفاده کنید یا خروجی را به ریشه یک شاخه انتشار منتقل کنید.
4. از تب **Actions**، workflow با نام `Xfinder Update` را یک بار با گزینه **Run workflow** اجرا کنید.
5. زمان‌بندی خودکار در فایل workflow روی هر 10 دقیقه تنظیم شده است. زمان‌بندی GitHub ممکن است با تأخیر اجرا شود و به فعال بودن Actions و شاخه پیش‌فرض نیاز دارد.

## حریم خصوصی و امنیت

- هیچ توکن یا رمز عبوری در پروژه لازم نیست.
- آدرس IP بازدیدکننده ذخیره یا برای تعیین زبان ارسال نمی‌شود؛ زبان بر اساس تنظیمات مرورگر انتخاب می‌شود.
- از کانفیگ‌های عمومی ممکن است اطلاعات اتصال حساس یا ناپایدار وجود داشته باشد. خروجی را عمومی نکنید مگر اینکه مجاز به انتشار آن باشید.
- این پروژه برای دور زدن کنترل دسترسی یا حمله به سرورها طراحی نشده است.
